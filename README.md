# Coding-lab_Group22 — KNH Digital Infrastructure Project

# About this project
 
The Kenyatta National Hospital has sensors that measure heart rate,
temperature, and water usage every second and save the data into
log files on a computer.

We built three shell scripts that:
- Set up the folders the system needs to store data
- Lock down patient data so only the owner can access it
- Search through patient readings and flag dangerous cases
- Calculate average ICU water usage
- Move old log files to storage and keep the system clean
